# GDP per Capita & Internet Usage – UN Data Analysis  

This project combines **GDP per capita** and **Internet usage percentage** data from the United Nations to explore global development and technology adoption trends. The analysis examines how wealth (GDP per capita) correlates with internet usage across countries and decades.  

This project was completed as part of the **Nashville Software School (NSS) Data Analytics Bootcamp**, focusing on Python, Pandas, and data visualization techniques.  

---

## Project Overview  

Using two datasets – `gdp_percapita.csv` and `internet_use.csv` – the analysis answers key questions【92†source】:  

- How is GDP per capita distributed globally in different years (1990, 2000, 2010, 2020)?  
- Which countries had the highest and lowest GDP per capita in 2020?  
- What countries had the earliest GDP per capita above $100,000?  
- How did internet usage spread globally, and what was the first year with non-zero usage?  
- Which countries had the highest percentage of internet users in 2014?  
- How do GDP and internet usage correlate across countries?  

Additional exercises included:  
- Creating **distribution plots** (histogram, density plot, boxplot, violin plot) for GDP per capita.  
- Tracking GDP per capita changes for selected countries.  
- Comparing internet usage distributions in 2000 vs. 2014.  
- Building a merged dataset (`gdp_and_internet_use`) for combined analysis.  
- Exploring relationships between **GDP groups (low/medium/high)** and internet adoption.

## Key Insights  

- Global GDP per capita increased significantly from 1990 to 2020, but with stark inequality between countries.  
- The **United States, Luxembourg, and Qatar** were among the first to surpass $100,000 GDP per capita.  
- Some countries had **lower GDP per capita in 2020 than in 1990**, reflecting uneven global development.  
- Internet usage rose sharply after the mid-1990s, with most countries having >50% penetration by 2014.  
- A **positive correlation** was observed between GDP per capita and internet usage in 2014, but with notable outliers.
